🧱 0. 前提（超重要）
Node.js 18 or 20 推奨
Windowsなら pnpmは使わない（Amplifyが非対応）
npmで統一する

Amplify Gen2 CLI を入れる
npm install aws-amplify @aws-amplify/backend-cli @aws-amplify/backend

backendフォルダ作成

プロジェクト直下に作る：
amplify/
  backend.ts
④ backend.tsを書く（最小構成）
import { defineAuth } from '@aws-amplify/backend';
export const auth = defineAuth({
  loginWith: {
    email: {
      otpLogin: true
    }
  }
});

⑤ AWS認証（初回だけ）
aws configure
⑥ sandbox起動（ここが本体）
npx ampx sandbox

⑦ amplify_outputs.jsonが生成される
成功するとこれが出る：
amplify_outputs.json

⑧ Next.jsで接続
import { Amplify } from "aws-amplify";
import outputs from "../amplify_outputs.json";

Amplify.configure(outputs);

npm run dev
